# Iris demo data

Downloaded on 2026-08-04 from Kaggle's [Iris Species](https://www.kaggle.com/datasets/uciml/iris) dataset (`uciml/iris`), file `Iris.csv`.

- 150 observations; four numeric flower measurements; a three-class `Species` label.
- The source CSV is preserved verbatim, including its `Id` column and `Iris-` species prefix.
- SHA-256 of the upstream `Iris.csv`: `600ac44f23c2e6e0ae37daac8ceb2baba4df963efa580eb31b3b576b28e34c55`.

Use `Species` for categorical colour encoding; it is also suitable for a marker-shape demonstration. Do not use `Id` as an analysis feature.
